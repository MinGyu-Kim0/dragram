# 복습 영역

FSRS 기반 복습은 후속 구현이며 아직 Django 실행 앱으로 등록하지 않는다.
현재 저장한 문장을 보여주는 기능은 백엔드 `library`와
프론트엔드 `features/library`가 담당한다.

복습 구현 시 이 영역이 학습 대상·평가 방향별 상태, 문제의 예문 선택,
평가 이력과 FSRS 일정 변경을 소유한다.
`services.py` 한곳에서 이력 생성과 일정 변경을 같은 트랜잭션으로 처리한다.

동일 요청 ID의 재전송뿐 아니라 서로 다른 요청 ID가 같은 이전 상태를 평가하는
경우도 검증한다. 상태 잠금과 버전 검사로 오래된 평가를 거절하는 정책을 확정한다.

`questions.py`는 정정·폐기된 문법 연결을 새 문제의 예문에서 제외한다.
과거 평가의 예문·설명 버전은 보존하며 다른 문법으로 숙련도를 자동 이전하지 않는다.
