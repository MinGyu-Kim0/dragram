# 시드 없이 LLM이 패턴을 쌓고, 미검수 지식도 표시를 붙여 재사용한다

문법 패턴을 미리 넣는 시드(JLPT 목록 등)는 공식 목록이 없고 혼자 만들기엔 작업량이 커서 두지 않는다. 처음 보는 문법은 분석 중 LLM이 찾아 미검수 패턴으로 등록하고, 미검수 지식도 승인 전부터 'AI 생성·미검수' 표시를 달아 보여준다. 이미 분석된 문장은 LLM 없이 그 결과를 재사용하고, 새 문장은 어차피 번역 때문에 부르는 LLM 호출 한 번에서 미검수 구간까지 함께 확인해 새 용법을 놓치지 않는다. 관리자 규칙(usage_rule)과 자동 승인 판단에는 승인된 지식만 쓴다.

## Consequences

- 초반 LLM 호출과 관리자 검수 대기열이 크다. 일일 상한은 초반에 넉넉히 잡는다.
- 이름만 다른 중복 패턴이 생길 수 있어 관리자 패턴 합치기가 필요하다(형태소 열 UNIQUE로 기술적 중복은 막는다).
