# 확정·미검수 표시는 구간에 저장하지 않고 조회할 때 정한다

구간(`span_match`)에는 고른 용법(`usage_id`)과 "용법이 하나로 정해졌다"(`decided`)만 저장하고, 확정(배지 없음)인지 'AI 생성·미검수'인지는 화면에 보낼 때마다 그 용법과 패턴의 검수 상태로 정한다. 구간에 `confirmed`/`reused`를 적어 두면 승인·반려가 있을 때마다 그 용법을 쓰는 모든 구간을 찾아 고쳐야 하고, 하나라도 놓치면 미검수가 검수처럼 보이는 불변식 위반이 생긴다. 검수 상태의 출처를 용법·패턴의 상태 칸 하나로 두면 이 어긋남이 구조적으로 생기지 않는다. 같은 이유로 새 문장에서 LLM이 미검수 용법을 고른 구간도 별도 상태 없이 같은 규칙으로 표시된다.

## Considered Options

- 구간에 `confirmed` / `reused(미검수)`를 저장 (기존 schema): 조회는 단순하지만 승인·반려 때 대량 갱신이 필요하고, 새 문장에서 LLM이 미검수 용법을 고른 경우를 담을 값이 없었다.
