# 내 일본어는 사용자가 직접 추가한 항목이고, 원문은 고른 예문만 저장한다

ADR 0002를 대체한다(2026-11-01, #321).

분석한 문장의 원문을 저장하지 않는다. 분석하는 동안만 서버와 OpenAI를 거친다. 내 일본어는 사용자가 사이드 패널의 문법·단어 카드에서 직접 **추가**한 용법·단어 뜻이다. 사용자별 테이블 `my_item`에 ID와 상태만 둔다. 같은 테이블에 **표시 안 함**(숨김) 상태도 두어, 숨긴 카드는 사이드 패널에서 접어 둔다. 카드를 추가한 뒤 사용자가 고른 문장만 `my_example`에 원문으로 남는다. 본인만 보며 언제든 지울 수 있다.

예전에는 분석할 때마다 원문을 `user_sentence`에 자동 저장했다. 내 일본어도 그 문장들의 공용 분석(`sense_ids`, `span_match`)에서 계산했다(ADR 0002). 사용자가 읽은 글이 전부 서버에 쌓이고, 운영자는 기술적으로 그 원문을 읽을 수 있었다. 저작권과 개인정보 부담이 컸고, 원하지 않는 항목까지 내 일본어에 섞였다(#293의 외부 조사).

## Considered Options

- 문장 저장 버튼(#293): 원문은 사용자가 저장한 문장만 남기고, 내 일본어는 저장한 문장에서 계산한다. 원문이 계산의 기준이라 저장을 피하기 어렵고, 원하지 않는 항목이 섞이는 문제가 남는다.
- 원문을 전혀 저장하지 않음: 개인정보·저작권 부담이 가장 적다. 하지만 학습 카드 예문(FR-M03)으로 쓸 원문이 없다.
- 직접 추가 + 고른 예문(채택): 저장하는 원문이 사용자가 고른 몇 문장으로 줄고, 예문은 계속 쓸 수 있다.

## Consequences

- 웹의 문장 목록과 문장별 분석 보기를 없앴다. 남은 `user_sentence` 행과 테이블을 없앨지는 배포할 때 정한다(더 쓰지 않는다).
- 분석 응답의 문법 항목에 `usage_id`, 단어 뜻에 `id`를 싣는다. 사이드 패널이 이 ID로 추가·숨긴다.
- 용법을 합치면 사용자 항목과 예문을 합친 용법으로 옮긴다. 추가가 숨김보다 앞선다. 반려된 용법·뜻의 항목은 웹에 내용 없이 예문만 보내, 사용자가 자기 원문을 지울 수 있게 한다.
- 한자는 아직 내 일본어에 넣지 않는다. 원문에서 뽑던 계산(ADR 0002)은 더는 쓸 수 없다. 한자를 넣을 때 다시 정한다.
- 학습 카드(FR-M03)의 등록·예문은 이 항목과 예문을 바탕으로 정한다.
