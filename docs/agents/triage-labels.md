# 트리아지 라벨

스킬들은 트리아지 역할 다섯 가지를 기준으로 말한다. 이 파일은 각 역할을 이 저장소의 이슈 트래커에서 실제로 쓰는 라벨 이름에 대응시킨다.

| mattpocock/skills의 라벨 | 우리 트래커의 라벨 | 뜻                                   |
| ------------------------ | ------------------ | ------------------------------------ |
| `needs-triage`           | `needs-triage`     | 관리자가 검토해야 함                 |
| `needs-info`             | `needs-info`       | 작성자에게 정보를 더 받아야 함       |
| `ready-for-agent`        | `ready-for-agent`  | 명세가 충분해서 에이전트가 혼자 처리할 수 있음 |
| `ready-for-human`        | `ready-for-human`  | 사람이 직접 구현해야 함              |
| `wontfix`                | `wontfix`          | 하지 않기로 함                       |

스킬이 역할을 말하면(예: "에이전트가 처리할 수 있다는 트리아지 라벨을 붙여라") 이 표에서 그 역할에 맞는 라벨 이름을 쓴다.

실제로 쓰는 라벨 이름이 다르면 "우리 트래커의 라벨" 칸을 고친다.
